`Pill Finder.dc.html`을 아래 내용대로 고쳐 주세요. 실제 앱 화면(pill-finder/)에 이미 반영한 수정이라 시안도 똑같이 맞추려는 것입니다. 구조와 나머지 동작은 그대로 두세요.

## 공통
1. 탭 묶음(직접 입력/사진/이름 검색, 약 정보의 탭 3개): 바탕을 진한 연회색(`var(--cal-surface-strong)`)의 둥근 네모(모서리 12px)로 바꾸고, 고른 칸은 흰색(모서리 8px)으로. 칸들이 탭 묶음 폭을 똑같이 나눠 가짐.
2. 연한 색은 아래 값으로 통일:
   - 연한 초록: `color-mix(in oklab, var(--cal-badge-emerald) 22%, white)`, 글자 `#0a3a28`
   - 연한 파랑: `color-mix(in oklab, var(--cal-brand-accent) 16%, white)`
   - 연한 노랑: `color-mix(in oklab, var(--cal-warning) 22%, white)`, 글자 `#78350f`
   - 연한 분홍: `color-mix(in oklab, var(--cal-badge-pink) 16%, white)`, 글자 `#9d174d`

## 화면 1 · 약 찾기
3. 각인·색·모양을 모두 정해야 "후보 찾기" 버튼이 눌리게. 각인은 앞이나 뒤 중 한 칸에 글자가 있거나 "각인 없음"·"마크(로고)"를 고르면 됨. 색은 색을 하나 이상 고르거나, "직접 색 입력하기"에 글자를 쓰거나, "알 수 없음"을 고르면 됨. 캡슐 여부는 선택.
4. 버튼이 안 눌릴 때 버튼 바로 위에 빠진 항목을 작은 회색 글씨(12px, 가운데)로: 예 "색·모양을 알려 주세요" (빠진 항목을 ·로 이어 "…을 알려 주세요").
5. 각인 칸 아래 안내: "한쪽에만 있으면 다른 칸은 비워 두세요. 대소문자·띄어쓰기는 무시합니다."
6. 사진 탭 버튼 이름 "후보 찾기" → "사진으로 각인 읽기". 버튼 바로 아래 작은 회색 글씨(12px, 가운데): "위치 정보를 지운 뒤 CLOVA로 보내 읽고, 사진은 저장하지 않습니다."

## 화면 2 · 후보 비교
7. 제목 아래 안내: "검색한 약의 후보입니다." (줄바꿈) "확정된 결과가 아니니 복용 전 약사에게 확인해 주세요."
8. 검색 조건 줄(예: `앞 tylenol · 뒤 5OO · 하양 · 장방형`), 후보 카드의 각인 값 줄(예: `TYLENOL / 500 · 하양 · 장방형`), 알약 그림 안의 글자: 고정폭 글꼴(mono) 대신 다른 글씨와 같은 기본 글꼴로.
9. 후보 카드에서 회사 이름과 그 아래 각인 값 줄 사이를 3px 더 벌림.
10. 배지 색: "일반" = 연한 파랑, "각인 완전 일치"·"색 일치"·"모양 일치"·"캡슐 여부 일치" = 연한 초록, "각인 부분 일치" = 연한 노랑. "전문"과 "불일치"는 회색 그대로.
11. 출처 상자: "받은 시각 2026-11-09 03:00" → "자료 기준 시점: 2026-11-09 03:00". "마지막으로 받은 자료 기준이며, 그 뒤에 등록·변경된 약은 반영되지 않았을 수 있습니다." 줄 삭제. 마지막 줄에서 "프로토타입 예시 데이터." 삭제("알약 그림은 값으로 그린 도식이며 실제 사진이 아닙니다."는 남김).
12. 화면 맨 아래 고정 영역에 "다른 알약 찾기" 버튼(크게, 폭 전체, 배경 연한 초록, 테두리 `var(--cal-badge-emerald)`, 글자 검정). 누르면 각인·색·모양·캡슐·이름 검색 입력값을 비우고 약 찾기 화면으로.

## 화면 3 · 약 정보와 질문
13. 맨 위 "일반의약품/전문의약품": 배지 상자를 없애고 동그라미 + 글씨만, 아래 약 이름과 왼쪽 끝을 맞춤. 동그라미 8px, 일반 = 연한 파랑 `#93c5fd`, 전문 = 연한 노랑 `#fde68a` (둘 다 얇은 테두리 `inset 0 0 0 1px rgba(0,0,0,.12)`).
14. 탭 이름: "쉬운 말 요약" → "요약", "공식 원문" → "원문", "질문" → "질문하기".
15. 요약 카드 제목 앞에 14px 아이콘: "무슨 약인가요" = 알약(캡슐) 모양, "어떻게 쓰나요" → 이름을 "어떻게 복용하나요"로 바꾸고 시계 아이콘, "주의할 점" = 경고 삼각형.
16. "AI 작성 · 모델 이름" 배지(요약과 답변 둘 다)를 연한 분홍으로.
17. 요약 아래 "공식 원문을 쉬운 말로 옮긴 것입니다. 원문 탭을 함께 확인하세요." 삭제.
18. 원문 제목: "사용 전 주의" → "복용 전 주의사항", "함께 쓰면 안 되는 약" → "함께 복용하면 안 되는 약". 원문 출처 상자에서 "프로토타입 예시 데이터" 삭제.
19. 본문(요약, 원문, 답변, 근거 문단): 왼쪽 정렬 + `text-wrap: pretty`. "머리·근육·생리통", "의사·약사와"처럼 ·로 이은 말은 줄 중간에서 끊기지 않게(`white-space: nowrap`으로 묶기).
20. 질문하기: 질문 입력칸 글씨를 예시 질문 버튼과 같은 13px로. 입력칸 아래 "공식 자료에 있는 내용만 답합니다" 삭제(글자 수 `0/300`만 오른쪽에 남김).
21. 진행 문구 "수업 서버 안에서 개인정보를 가리는 중입니다" → "개인정보를 가리는 중입니다".
22. 보내기 전 확인 문구: "아래 문장만 CLOVA·Claude(으)로 전송됩니다. 원래 질문은 서버 밖으로 나가지 않습니다." → "아래 문장으로 바뀌어 CLOVA·Claude(으)로 전송됩니다."
23. 맨 아래 안내: "이 정보는 법적 효력이 없으며 의약품에 관한 모든 내용을 담고 있지 않습니다." (줄바꿈) "복용 전 약사에게 확인하세요." 글씨 12px, 가운데 정렬, `text-wrap: balance`.
24. 화면 맨 아래 고정 영역에 화면 2와 같은 "다른 알약 찾기" 버튼.
